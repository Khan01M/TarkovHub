# Tarkov Hub

Справочник по Escape from Tarkov. Один код работает как сайт, как приложение для Android (APK) и как программа для Windows (EXE) и macOS.

**Что есть**
- **Барахолка**: цены за 24 часа, изменение за 48 часов, лучший торговец для продажи, цена за клетку, фильтр по категориям.
- **Оружие и патроны**: отдача, эргономика, скорострельность; таблица патронов с пробитием по цвету класса брони.
- **Боссы**: шанс спавна по картам, точки появления, охрана, здоровье, короткие тактики.
- **Карты**: схема выходов (ЧВК, Дикий, общие) и точек спавна, боссы на карте, ваша позиция.
- **Квесты**: фильтры по торговцу, карте и квестам для Каппы, трекер выполненных.
- **Гайды**: новичкам, заработок, патроны, лечение, лут-маршруты. Новые гайды добавляются в `src/guides.ts`.
- Переключатель **PvP/PvE**. Данные кэшируются, поэтому последние загруженные цены видны и без сети.

Данные берутся из открытого JSON API [tarkov.dev](https://json.tarkov.dev/endpoints) (бесплатно, без ключа). GraphQL API tarkov.dev с июля 2026 года не работает, поэтому используется JSON API — на нём работает и сам сайт tarkov.dev.

## Связь с игрой (версия для ПК)
Приложение не читает память игры и не вмешивается в её процесс, поэтому оно не нарушает правила.
1. **Позиция.** EFT записывает координаты в имя каждого скриншота. Программа следит за папкой
   `Документы\Escape from Tarkov\Screenshots`, а после нажатия PrtSc в рейде ставит на карту точку и показывает направление взгляда.
2. **Автовыбор карты.** Программа читает логи игры (`<папка игры>\Logs`) и по строке `Location: …` определяет, какая карта загрузилась.
3. Меню «Вид → Поверх всех окон» удобно для второго монитора.

В версии для сайта и APK позицию можно отметить вручную: вставьте имя скриншота или координаты «x, y, z».

## Как получить APK и EXE (без установки чего-либо на компьютер)
1. Создайте репозиторий на GitHub и загрузите туда эту папку.
2. В репозитории откройте **Settings → Pages → Source: GitHub Actions**.
3. Сборка запустится сама при каждом push. Готовые файлы лежат в разделе **Actions → последний запуск → Artifacts**:
   - `TarkovHub-android`: APK для телефона;
   - `TarkovHub-windows`: установщик и portable EXE;
   - `TarkovHub-macos`: DMG;
   - сайт появится по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.
4. Если поставить тег `v1.0.0` (`git tag v1.0.0 && git push --tags`), файлы приложатся к странице Releases.

APK собирается в отладочном режиме: его можно ставить на телефон («Разрешить установку из неизвестных источников»).
Для публикации в Google Play нужна release-сборка с ключом подписи.

## Разработка на своём компьютере
```bash
npm install
npm run dev          # сайт на http://localhost:5173
npm run build && npm run electron   # десктопная версия
npm run dist:win     # EXE (запускать на Windows)
npm run dist:mac     # DMG (запускать на Mac)
npm run android:sync # затем открыть папку android в Android Studio → Build APK
```
Нужен Node.js 22+. Для Android нужен Android Studio и JDK 21. Перед первым запуском выполните `npx cap add android`.

## Безопасность
- Десктопное окно работает в песочнице: `contextIsolation`, `sandbox`, без `nodeIntegration`. Уйти со своей страницы окно не может, новые окна не открываются.
- Во внешний браузер уходят только ссылки http(s). Ссылки из API тоже фильтруются (`safeUrl` в `src/ui.tsx`).
- Content-Security-Policy: скрипты только из самого приложения, сетевые запросы только к `json.tarkov.dev`, картинки только с `assets.tarkov.dev`.
- IPC принимает сообщения только от страницы приложения. Запросы разрешений (камера, микрофон и т. п.) отклоняются.
- В GitHub Actions по умолчанию выдаются права только на чтение. Запись в Pages и Releases разрешена только задачам публикации.

## Структура
- `src/pages/`: разделы сайта
- `src/api.ts`: загрузка данных с json.tarkov.dev, перевод на русский и кэш
- `src/position.ts`: разбор координат из имени скриншота
- `src/guides.ts`: тексты гайдов
- `electron/`: десктопная оболочка и интеграция с игрой
- `.github/workflows/build.yml`: автосборка сайта, APK, EXE, DMG

*Неофициальный фан-проект, не связан с Battlestate Games.*
